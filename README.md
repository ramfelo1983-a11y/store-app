# سجل المشتريات والمصروفات 📦

## خطوات رفع الكود على Codemagic وتنزيل APK

### 1. ارفع الكود على GitHub (مجاني)
1. اذهب إلى **github.com** وسجل حساب جديد (لو مش عندك)
2. اضغط **New Repository** → اسمه `store-app` → اضغط **Create**
3. حمّل ملفات المشروع كلها (كل المجلد) على الـ Repository

### 2. اربط Codemagic بـ GitHub
1. اذهب إلى **codemagic.io** (انت مسجل فيه)
2. اضغط **Add application**
3. اختار **GitHub** → اختار الـ repository `store-app`
4. اختار **Flutter App**

### 3. ابني الـ APK
1. في Codemagic اضغط **Start new build**
2. اختار workflow: **Android Build**
3. اضغط **Start build**
4. استنى 5-10 دقايق → هتلاقي زرار **Download APK**

### 4. نزّل على الموبايل
1. حمّل الـ APK على موبايلك
2. افتح إعدادات الأندرويد → السماح بالتثبيت من مصادر غير معروفة
3. افتح الملف وثبّته
